Install steps

Six steps, in this order.

Follow them in order. Don’t attach the EA before the licence URL is added.

01

Save the EA file

Download the .ex5 file from our downloads page or get it on Telegram, plus a preset file if provided.

Save it somewhere easy, like Downloads or Desktop. You need a computer. EAs can’t be installed on a phone.

Only use files from our website or Telegram. Copies from elsewhere may be old and won’t match your licence.

02

Open the data folder from inside MT5

In MetaTrader 5, use the menu:

File ▸ Open Data Folder

Don’t look for the folder manually. If you have more than one MT5 installed, each has its own data folder and they look the same. Opening it from inside MT5 makes sure you use the right one. This is the most common mistake.

03

Copy the EA into Experts

Open MQL5 → Experts and paste the .ex5 file there.

Data folder / MQL5

├── Experts/     ← Gold Crack EA .ex5 goes here
├── Presets/     ← .set preset file, if provided

EAs placed in Indicators or Scripts won’t show up under Expert Advisors.

04

Refresh the Navigator panel

In MT5, right-click Expert Advisors in the Navigator panel and click Refresh. Gold Crack EA should appear.

Not there? Restart MT5. Still missing? The file is in the wrong folder. Go back to step 02.

05

Allow WebRequest for the licence URL

The EA checks its licence online every hour. Without this URL, the check fails and the EA stops trading.

Tools ▸ Options ▸ Expert Advisors

A smiley face at the top right means the EA is running. A sad face means algo trading is off. Check the Algo Trading button in the toolbar.

If something is wrong

Problems and fixes.

The EA is not in the Navigator list
Usual cause — wrong folder

The file is in another MT5’s folder, or in Indicators instead of Experts. Use File → Open Data Folder in the MT5 you want, put the .ex5 in MQL5 → Experts, then refresh Navigator.

A licence error appears on the chart
Usual cause — URL missing, or account not bound

Check the WebRequest URL is exactly https://a689.link. If the error stays, your account may not be activated yet. Send your account number and registered email on Telegram.

The EA loads but never opens an order
Usual cause — wrong symbol, or a pause is active

Check the chart uses your broker’s XAUUSD symbol (some add a suffix). If it does, the EA may be paused for rollover or high-impact news. This is normal.

It was running, then stopped mid-session
Usual cause — licence recheck failed

The licence is checked every hour. If it expired or can’t reach the server, pending orders are removed and no new trades open. Check the WebRequest URL and your internet.

Trades were left unmanaged overnight
Usual cause — terminal was closed

The EA only works while MT5 is running. If MT5 closes or the PC sleeps, open trades aren’t managed. Use a Windows VPS if you can’t keep it on.
